Sound 页 · 像素风 6 个样本

每个是一个独立的方向。点进去看完整效果再决定哪个用做 /expressions_sound.html 的最终版（或者告诉我「混 A + C」之类）。

A · Cassette

磁带店 · 米黄&深棕

点阵字 + 旋钮 + 磁带卡带轮转。怀旧暖色，像 80 年代音像店窗口。

B · Game Boy

绿屏 4 色

经典 GB 四阶绿、Press Start 2P、像素边框、低保真音波。

C · Terminal

琥珀终端

黑底 + 琥珀色磷光字，CRT 扫描线，命令行播放器。

D · PICO-8

PICO-8 16 色

饱和明亮的 16 色调色板，圆角像素块，迷你游戏机壳。

E · Music Box

八音盒纸带

米白纸带 + 黑色孔洞 + 印章字体。八音盒主题最具体的还原。

F · Synthwave

合成器 / 霓虹夜

深紫底 + 霓虹粉紫青、网格地平线、像素星星。Vaporwave 系亲戚。
